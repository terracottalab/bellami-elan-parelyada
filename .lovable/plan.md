# Упрощение CTA в чат-виджете

## Что будет изменено

В чат-виджете останется только одна кнопка эскалации — «Связаться с владельцем» / «Contact the owner». Кнопка «Отправить запрос владельцу» / «Send an enquiry to the owner» удаляется.

Кнопка «Связаться с владельцем» становится активной только после того, как пользователь отправил хотя бы одно собственное сообщение (не считая приветственное сообщение ассистента и кликов по быстрым вопросам). До этого момента кнопка неактивна и визуально приглушена.

## Зачем

- Убирается дублирование похожих действий: пользователю проще понять, как попросить владельца о связи.
- Собственное сообщение гарантирует, что в тикете есть контекст — владелец видит, о чём просит пользователь.

## Техническая часть

- В `src/components/ChatWidget.tsx`:
  - удалить импорт и вызов `createEnquiryFromChat`;
  - удалить `handleEnquiry`, `enquiryCta`, `enquirySent` и кнопку «Отправить запрос владельцу»;
  - оставить только `handleContact` и кнопку «Связаться с владельцем»;
  - добавить условие активности кнопки: `disabled`, пока в `messages` нет сообщения с `role === "user"`;
  - при клике по быстрым вопросам сообщение пользователя тоже считается собственным сообщением.
- В `src/lib/chat.functions.ts` функция `createEnquiryFromChat` остаётся нетронутой, так как она может использоваться в других местах; из виджета она просто перестаёт вызываться.
- Проверка: `npx tsgo --noEmit` и визуальная проверка виджета в preview.
