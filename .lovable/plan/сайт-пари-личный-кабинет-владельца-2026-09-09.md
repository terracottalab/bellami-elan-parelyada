# Сайт Пари + личный кабинет владельца

Переносим готовый лендинг (RU/EN) в этот проект один в один по дизайну и добавляем закрытый кабинет со статистикой: заявки, посещаемость, выставки и деньги.

## Что получится

**Публичный сайт**
- Главная на русском (`/`) и английская версия (`/en`), с тем же текстом, фотографиями, галереей с увеличением, фильтрами по выставкам и переключателем языка.
- Страницы «Политика конфиденциальности» и «Условия» на обоих языках.
- Форма заявки на щенка работает без PHP: заявка сохраняется в базе и приходит письмом на contact@norwichterrier.info. Защита от спама сохраняется (скрытое поле + ограничение частоты отправки).
- Все фото переносятся как ассеты сайта.

**Кабинет (вход только для вас)**
- Вход по почте и паролю, чужие регистрации закрыты.
- Сводка: заявки за период, посетители, ближайшие выставки, баланс доходов и расходов.
- Заявки: список с фильтрами, карточка заявки, статусы (новая, в работе, одобрена, отказ), заметки, выгрузка в CSV/Excel.
- Посещаемость: просмотры страниц по дням, разбивка по языку, странице и источнику перехода; учёт ведётся своим счётчиком без сторонних сервисов, без хранения полного IP.
- Выставки и титулы: справочник выставок (дата, страна, класс, результат, титул) и расходы на поездки.
- Деньги: доходы (брони, предоплаты, оплаты за щенков) и расходы (выставки, ветеринария, содержание, прочее) по категориям и помётам; итоги за месяц/год, отчёт по периоду с выгрузкой.
- Интерфейс кабинета на русском.

## Технические детали

- Стек проекта: TanStack Start + React + Tailwind. Стили лендинга переносятся в дизайн-систему проекта (токены цветов и шрифтов в `src/styles.css`), разметка — в компоненты; визуально 1:1 с оригиналом.
- Маршруты: `/`, `/en`, `/ru/legal/privacy`, `/ru/legal/terms`, `/en/legal/privacy`, `/en/legal/terms`, `/auth`, `/_authenticated/admin/*` (сводка, заявки, посещаемость, выставки, финансы).
- Включаем Lovable Cloud (база, вход, серверные функции).
- Таблицы: `enquiries`, `enquiry_notes`, `page_views`, `shows`, `finance_entries`, `litters`, `profiles`, `user_roles` (роль в отдельной таблице, проверка через `has_role`).
- RLS: публичная вставка только в `enquiries` и `page_views` через серверные функции с валидацией и ограничением частоты; чтение — только для роли `admin`. GRANT-ы прописываются вместе с таблицами.
- Отправка письма о новой заявке — серверной функцией; адрес и ключ почтового сервиса хранятся в секретах.
- Счётчик посещений: серверная функция пишет страницу, язык, реферер, хеш посетителя (без сырого IP), user-agent в укрупнённом виде.
- SEO: уникальные `head()` на каждой странице, `lang`/`hreflang` RU↔EN, canonical, alt-тексты, ленивые изображения; кабинет закрыт от индексации.
- Форма проверяется на сервере (Zod) и на клиенте, сохраняются исходные обязательные поля и согласие.
- После сборки прогоню проверку безопасности и отдам отчёт.
