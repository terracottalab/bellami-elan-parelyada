# Уменьшение TTL для ускорения подключения домена

## Цель
Сократить время распространения DNS-изменений для домена `norwichland.com`, чтобы Lovable быстрее увидел записи и завершил верификацию.

## Что сейчас
- A-записи `www` и `@` уже имеют TTL `300` (5 минут) — их трогать не нужно.
- TXT-записи `_lovable` и `_lovable.www` имеют TTL `14400` (4 часа) — их нужно уменьшить.

## План
1. В панели управления DNS домена `norwichland.com` отредактировать TXT-запись `_lovable`:
   - Оставить содержимое без изменений.
   - Изменить TTL с `14400` на `300` (или `600`, если регистратор не принимает 300).
2. То же самое сделать для TXT-записи `_lovable.www`.
3. Сохранить изменения.
4. Подождать, пока старый кэш TTL в 4 часа истечёт (максимум 4 часа с момента первоначальной установки записей).
5. Проверить статус домена в настройках проекта Lovable → Domains → "Проверить статус".

## Ожидаемый результат
DNS-записи будут обновляться быстрее, и верификация домена в Lovable пройдёт раньше.
